# Made For You

Custom app that adds a "Made For You" link to the sidebar and redirects to Spotify's Made For You hub (`/genre/0JQ5DAt0tbjZptfcdMSKl3`).

Replaces "Made for you" shortcut (Pithaya), which no longer mounts in the current sidebar. As a custom app, spicetify places the link itself, so it survives sidebar changes.

Install: symlink this folder to `~/.config/spicetify/CustomApps/made-for-you`, then `spicetify config custom_apps made-for-you && spicetify apply`.
