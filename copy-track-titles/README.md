# Copy Track Titles

<img src="https://raw.githubusercontent.com/WybeBosch/w-spicetify-extensions/main/copy-track-titles/preview.png" width="320" alt="Copy Track Titles">

Select one or more tracks, right-click, "Copy titles". Copies `Artist, Artist - Title` lines to the clipboard.

Uses the client's internal GraphQL `getTrack` query, so no Web API calls.
